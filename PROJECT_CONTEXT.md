# Memorix

Telegram-бот для хранения личной информации и быстрого поиска по ней.

---

# Основная идея проекта

Memorix — это «вторая память».

Пользователь может переслать в бота практически любой контент:

* текст
* голосовое сообщение
* кружок Telegram
* фотографию
* альбом фотографий
* видео
* PDF
* DOCX
* XLSX
* PPTX
* пост из Telegram-канала
* сообщение со ссылками и форматированием

Бот сохраняет контент, автоматически присваивает:

* категорию
* тип контента
* теги

После чего пользователь может найти информацию через поиск.

# Ключевой принцип разработки

Проект находится в стадии MVP.

Главная цель сейчас:

СТАБИЛЬНОСТЬ.

Любая новая функция должна:

1. Не ломать существующие сценарии.
2. Не менять архитектуру без необходимости.
3. Не требовать миграции старых данных.
4. Сохранять обратную совместимость.

Запрещено:

* делать крупные рефакторинги без необходимости;
* переписывать работающие блоки;
* менять callback_data существующих кнопок;
* менять структуру БД без крайней необходимости.

# Форматирование

Проект пытается сохранять Telegram HTML formatting.

Используется поле:

formatted_text

При наличии formatted_text отображается он.

Если formatted_text отсутствует:

используется text.

Цель:

сохранять:

* ссылки
* жирный текст
* курсив
* подписи медиа

---

# Поиск

Команда:

/search

Также работает поиск через интерфейс.

Поиск возвращает карточки записей.

---

# Карточка записи

Карточка должна содержать:

* превью
* категорию
* тип контента
* теги

И кнопки:

🗑 Удалить

🔎 Похожее

📌 Закрепить

✏️ Изменить

🏷 Ред. теги

📂 Ред. категорию

---

# Полный просмотр записи

Callback:

full:<id>

Показывает:

* полный текст
* метаданные
* вложения

Важно:

если запись содержит фото:

текст и фото должны отображаться как единое сообщение через caption.

Для альбомов:

caption должен прикрепляться к первому элементу media group.

---

# Похожие записи

Callback:

similar:<id>

Используются OpenAI embeddings.

Поиск должен работать только внутри записей пользователя.

---

# Редактирование

## Редактирование текста

Callback:

edit_memory:<id>

Показывается текущий текст.

Текст выводится в monospace-блоке для быстрого копирования.

После изменения:

показывается карточка:

Обновлено 🔄

Содержит:

* категорию
* тип контента
* теги
* старая версия
* новая версия

---

## Редактирование тегов

Callback:

edit_tags:<id>

Название кнопки:

🏷 Ред. теги

---

## Редактирование категории

Callback:

edit_category:<id>

Название кнопки:

📂 Ред. категорию

---

# Удаление

При удалении записи необходимо удалять:

1. запись из БД
2. зарегистрированные сообщения бота

Для этого используется:

register_memory_message()

---

# Система отмены

Команда:

/cancel

Кнопка:

⬅️ Назад

Должна работать в любых FSM-состояниях:

* поиск
* редактирование текста
* редактирование тегов
* редактирование категории

После отмены FSM обязательно очищается.
